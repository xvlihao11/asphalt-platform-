# 越南北南高速铁路670亿美元项目——基建投资拉动沥青需求

> 来源：京博海南沥青出口国家 / 深度研究报告 | 2026-08-17

## 📰 原文摘要

根据商务部《对外投资合作国别（地区）指南》，北南高速铁路是越南当前最重大的基础设施项目，总投资高达670亿美元。同时，北南高速公路东部路段（第二期）12个子项目的招标方案已获批。大规模基建投资将持续拉动沥青进口需求。

## 🔍 深度分析

**行业背景**：基于上述新闻，该动态涉及沥青出口目标国家的产业政策、标准更新或市场变动。需结合京博海南当前出口布局进行研判。

**关键要点**：
- 670亿美元高铁项目 + 高速公路二期12个子项目 = 越南基建大周期
- 高速公路建设直接拉动沥青进口需求，尤其是面层和基层沥青
- 京博海南每月向越南发运160-170吨特种沥青，需评估扩产空间
- 高铁项目间接影响物流通道，可能降低沥青运输成本

2. 跟踪北南高速公路东部路段二期12个子项目招标进展，寻找参与机会
