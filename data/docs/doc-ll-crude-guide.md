# 原油评价学习指南（沥青方向）


面向即将入职沥青相关公司、第一个任务为"原油评价"的新人。本文梳理：为什么沥青公司要做原油评价 → 学习路线图 → 完整试验流程与项目 → 沥青（减压渣油）专项评价 → 国内外标准与手册清单 → 入职实操建议。
标准版本信息核实时间：2026 年 8 月。

## 一、先想清楚：沥青公司做原油评价，评价的是什么？

炼油厂做原油评价是为了设计全流程加工方案；沥青公司的原油评价，核心目标是回答三个问题：

- 这种原油适不适合生产沥青？——看减压渣油收率、组成（蜡含量、四组分）和基属（环烷基、中间基原油通常是优质的沥青原料）。
- 能生产出什么牌号、什么等级的沥青？——对渣油（或经氧化、调合、溶剂脱沥青后的产物）测针入度、软化点、延度、蜡含量、老化后残留物性能等，对照 GB/T 15180、NB/SH/T 0522、JTG F40 的指标判断。
- 用什么工艺路线最好？——直馏、氧化、调合、溶剂脱沥青，或几种组合。
因此你的学习主线是：原油一般性质 → 实沸点蒸馏切割 → 窄馏分与重油性质分析 → 减压渣油的沥青性能评价 → 加工方案建议 → 评价报告。前四步与炼厂评价完全相同，第五步是沥青公司的特色与重点。

## 二、学习路线图（建议按 4 个阶段推进）

### 阶段 1：打基础（1~2 周）

- 石油化学基础：烃类组成（烷烃、环烷烃、芳烃）、非烃（硫、氮、氧、金属）、胶质沥青质概念。
- 原油分类方法：





- 按密度/API 度：轻质、中质、重质、超重质原油；
- 按硫含量：低硫（<0.5%）、含硫（0.5%~2%）、高硫（>2%）；
- 按蜡含量：低蜡、含蜡、高蜡原油；
- 按特性因数 K 值 / 关键馏分特性分类：石蜡基、中间基、环烷基——沥青行业最关心这一条，环烷基和低蜡中间基原油是公认的优质沥青原料。
- 推荐教材：《石油炼制工程》（徐春明、杨朝合主编，石油工业出版社）第 1~2 章"石油的化学组成"与"石油及油品的物理性质"。
### 阶段 2：掌握原油一般性质分析（2~3 周，可进实验室跟岗）

逐项学会：取样与脱水 → 密度、粘度、凝点/倾点、闪点、水分、盐含量、机械杂质、硫含量、残炭、灰分、蜡/胶质/沥青质含量、金属（镍、钒）含量、馏程。
每个项目要搞清楚四件事：测什么、为什么测（对沥青生产的意义）、用什么标准方法、仪器怎么操作。

### 阶段 3：攻克实沸点蒸馏（TBP）与窄馏分分析（3~4 周，核心）

这是原油评价的"黄金方法"，也是你最该下功夫的部分：
- 装置原理：间歇釜式精馏，理论塔板数 14~18 块，回流比 5:1；
- 三段蒸馏操作：常压蒸馏 → 减压蒸馏（约 10 mmHg）→ 二段减压蒸馏（1~2 mmHg，不带精馏柱）；
- 关键控制点：釜底温度不得超过 350 ℃（防裂解），馏出物最终沸点一般 500~520 ℃（AET，常压相当温度）；
- 数据处理：绘制实沸点蒸馏曲线、窄馏分中比性质曲线、直馏产品产率-性质曲线。

### 阶段 4：沥青专项评价与报告编写（持续）

- 减压渣油三大指标（针入度、软化点、延度）+ 蜡含量 + 四组分 + 老化试验（TFOT/RTFOT）+ 60 ℃动力粘度；
- 必要时做氧化、调合、脱沥青小试，确定工艺路线；
- 对照产品标准判定可产牌号，编写完整评价报告。
## 三、原油评价的分级与完整试验内容

国内通行的做法把原油评价分为四级（由简到繁）：

||||
|---|---|---|
|原油性质分析|掌握原油一般性质及变化|密度、粘度、凝点、水分、盐、硫等基本性质|
|简单评价|原油性质普查，初定特点|一般性质 + 简易蒸馏（馏分收率）|
|常规评价|为一般炼厂提供设计数据|一般性质 + 实沸点蒸馏窄馏分分析 + 重油/渣油性质 + 直馏产品性质|
|综合评价|为综合型炼厂/化工型炼厂提供设计数据|常规评价全部 + 化学组成分析 + 产品潜含量 + 平衡气化数据 + 渣油（沥青）性质及组成测定|


### 3.1 第一步：取样与预处理

- 按 GB/T 4756《石油液体手工取样法》取代表性样品；
- 含水量 >0.5% 时必须先脱水（加热沉降、离心或电脱水），否则影响蒸馏与分析；
- 同时测定水、盐、机械杂质，为后续数据修正提供依据。
### 3.2 第二步：原油一般性质分析（常规评价项目清单）

||||
|---|---|---|
|密度（20 ℃）/API 度|GB/T 1884、GB/T 13377（振动管法）|判断轻重、估算渣油收率、基属初判|
|运动粘度|GB/T 265、GB/T 11137（深色油品）|输送与加工难度|
|凝点 / 倾点|GB/T 510 / GB/T 3535|反映蜡含量高低，蜡高不利沥青低温性能|
|闪点|GB/T 261（闭口）、GB/T 3536（开口）|安全与轻质油含量|
|水分|GB/T 8929（蒸馏法）、GB/T 6533（离心法）|蒸馏前必须控制|
|盐含量|GB/T 6532（电量法/电位滴定）|腐蚀与催化剂污染|
|硫含量|GB/T 17040（X 荧光）等|腐蚀、环保、产品等级|
|残炭（康氏/微量）|GB/T 268、GB/T 17144|重质组分与生焦倾向|
|灰分|GB/T 508|金属杂质水平|
|蜡、胶质、沥青质|SY/T 7550 等|沥青原料评价核心：蜡低、胶质沥青质适中方好|
|镍、钒等金属|GB/T 18608 等|催化剂中毒、灰分来源|
|馏程（恩氏蒸馏）|GB/T 6536|快速了解轻重组分分布|


### 3.3 第三步：实沸点蒸馏（TBP）——评价的核心试验

装置与条件（执行 GB/T 17280《原油蒸馏标准试验方法》，等效 ASTM D2892）：
- 间歇式釜式精馏设备，理论塔板数 14~18 块，回流比 5:1；
- 三段操作：
  1. 常压蒸馏：切割至常压 200 ℃左右（或到釜温限制前）；
  2. 减压蒸馏（约 10 mmHg ≈ 1.33 kPa）：继续切割；
  3. 二段减压蒸馏（1~2 mmHg ≈ 133~266 Pa，不带精馏柱）：深拔至相当于常压 500~520 ℃；
- 釜底温度全程不得超过 350 ℃，防止热裂解导致数据失真；
- 釜底残留物即减压渣油——这是沥青评价的主角。

减压深拔段执行 GB/T 17475《重烃类混合物蒸馏试验方法（真空釜式蒸馏法）》，等效 ASTM D5236，可拓展到相当于常压 565 ℃左右。

窄馏分切割：一般按累计馏出每 3%（或 3%~5%）取一个窄馏分，按馏出顺序编号、称重、量体积，计算收率，并逐个测定性质（密度、粘度、凝点、折射率、硫、氮、苯胺点、酸度/酸值等），计算特性因数 K、粘重常数、结构族组成。

三条核心曲线（评价报告的骨架）：
1. 实沸点蒸馏曲线：馏出温度（常压相当温度）对累计馏出质量分数——看馏分分布；
2. 中比性质曲线：假定窄馏分性质代表其馏出一半时的性质而标绘——预测任意窄馏分性质（注意：除相对密度外性质无加和性，只能看变化趋势，不能直接用于切割方案）；
3. 产率-性质曲线：直馏产品收率随切割点/性质的变化——确定产品方案。

### 3.4 第四步：重油与减压渣油性质分析

对不同拔出深度（如 >400 ℃、>500 ℃、>520 ℃、>540 ℃）的重油和渣油测定：
- 密度、粘度（100 ℃/135 ℃/150 ℃）、凝点、闪点、残炭、灰分；
- 元素分析（C、H、S、N）与镍、钒金属；
- 四组分（饱和分、芳香分、胶质、沥青质）；
- 沥青质量指标：针入度、延度、软化点、蜡含量——直接初判沥青生产适宜性。

### 3.5 第五步：沥青生产适宜性判断与工艺小试

根据渣油数据做判断（行业经验规律）：
- 渣油收率高（重质原油可达 40%~50% 以上）→ 沥青路线经济性才成立；
- 蜡含量低（一般要求沥青蜡含量 ≤2.2%~4.5%，视等级）→ 石蜡基原油（如大庆）通常不适合直接产优质道路沥青；
- 四组分匹配：经验上饱和分约 8%~15%、芳香分 30%~55%、胶质 25%~45%、沥青质 1%~10% 时性能较好；
- 渣油针入度太大、软化点太低（如针入度 >300、软化点 <30 ℃）→ 需氧化或深拔提高硬度；
- 渣油太硬、延度差 → 可考虑与软组分调合，或溶剂脱沥青调整组成。

必要时开展小试：蒸馏法（不同拔出深度）、氧化法（考察温度、通风量、氧化时间对三大指标的影响）、调合法（两种渣油/渣油+软组分比例扫描）、溶剂脱沥青。氧化过程一般呈"软化点随氧化时间线性升高、针入度随软化点升高指数下降"的规律，可据此预测目标牌号所需工艺条件。

### 3.6 第六步：编写原油评价报告

典型报告章节：
1. 原油来源与基本概况；
2. 原油一般性质表；
3. 实沸点蒸馏收率数据表 + 蒸馏曲线；
4. 窄馏分性质表 + 中比性质曲线；
5. 重油/渣油性质表（不同拔出深度）；
6. 渣油沥青性能评价（三大指标、蜡含量、四组分、老化后残留物）；
7. 直馏产品切割方案与产率-性质曲线；
8. 结论与加工方案建议（基属判定、适宜产品、推荐工艺路线）。

## 六、入职实操建议（避坑指南）

- 先学安全再学操作：高温（350 ℃釜温）、高真空、易燃样品、三氯乙烯等溶剂——实沸点蒸馏和沥青试验都是高温作业，务必先过实验室安全培训。
- 样品代表性是第一位：取样、脱水、混匀做得不规范，后面数据全废。水分超 0.5% 必须先脱水再蒸馏。
- 守住关键工艺参数：回流比 5:1、釜温 ≤350 ℃、真空度稳定、馏出速率——这是数据可比性的前提。
- 注意温度换算：减压下读的温度要换算成常压相当温度（AET）才能画 TBP 曲线，掌握换算表/图的使用。
- 数据闭环检查：各窄馏分收率加和应接近 100%（一般 97%~100%），损失过大要找原因（漏气、挂壁、裂解）。
- 新版标准过渡期问题：JTG 3410-2025 与 GB/T 15180-2025 刚实施不久，报告引用标准时确认客户/公司要求用新版还是旧版，指标限值已有变化（如 AH 牌号体系）。
- 建立"组成-性质-工艺"思维：同一油种不同工艺、不同油种相同工艺，即使四组分含量接近，路用性能也可能差异很大（化学结构与相溶性不同）——不要只看单个指标下结论。
- 学会读历史数据：把公司过往油种的"原油性质 → 渣油性质 → 沥青指标 → 工艺路线"串起来对比，是最快的经验积累方式。
